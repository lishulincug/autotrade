# 每日投资分析 Python 工具

供北京时间 **09:50 自行运行**。Python 3.10 或更高版本，无须安装第三方库、申请 API Key 或付费服务。程序只采集数据并生成报告，不下单，不发送消息，也不自行创建定时任务。

## 开始运行

解压后，在本文件所在文件夹打开终端：

```powershell
python daily_analysis.py
```

Windows 也可双击 `run_daily.bat`。报告保存在同一文件夹的 `reports` 中，包括可阅读的 Markdown 和便于后续处理的 JSON。每次生成独立文件；所有时间统一为北京时间，报价保留各自时间。

如电脑的命令是 `py`，可以改为 `py daily_analysis.py`。双击窗口结束后可能关闭，可从终端运行以查看错误。

## 覆盖范围与报告

初始关注列表包括30年国债ETF博时（511130）、十年国债ETF（511260）、中证红利、纳指科技ETF（159509）、恒生科技、黄金、油气、北证50和创业板。

- 最新价格、相对昨收涨跌和报价质量；历史报价不会冒充当日行情。
- MA5/20/60、5/20/60交易日价格变化、样本最大回撤、样本年化波动率。
- 关注资产的相对强弱排序、趋势提示、长债久期及成长资产集中度检查。
- 提供符合要求的同期参考价值后，计算折溢价并检查警戒线。
- 输入真实成本后粗估价格盈亏；没有成本时不输出个人盈亏。

日线指标始终使用**今日之前的完整日线**，包括收盘后运行。公开接口请求最近约260条日线；本地数据的回撤和波动计算使用你提供的全部有效历史。年化按252交易日计算，是样本统计，不是未来风险上限。前复权价格变化不保证等同基金含分红总收益；不同市场交易日也可能不一致。

## 先改真实持仓

编辑 `config.json`。原始仓位和成本全部留空，你之前回复的“20%”含义尚不确定，程序没有将其作为仓位或回撤限制。

|字段|含义|
|---|---|
|`symbol`|腾讯行情代码，例如沪市 `sh511260`、深市 `sz159509`|
|`secid`|东方财富日线标识；沪市常见 `1.代码`，深市常见 `0.代码`，其他市场需核实|
|`currency`|报价币种；内地ETF通常 `CNY`，香港指数通常 `HKD`|
|`weight`|占总账户比例，20%填写 `0.20`；未知保留 `null`|
|`cost`|每份基金平均买入成本，必须与报价币种、单位相同；未知保留 `null`|
|`group`|用于集中度检查，例如 `growth`、`long_bond`、`dividend`、`gold`、`energy`|
|`proxy`|是否仅为观察代理；换成实际持有产品后删除此字段或设为 `false`|
|`is_index`|是否指数点位；换成实际基金后删除此字段或设为 `false`|

**黄金暂用518880观察，石油暂用561360油气股票ETF观察，它们不是已经确认的本人持仓。油气股票ETF不等于原油期货/现货。** 必须换成你真正持有的代码，才能输入这些品种的仓位进行分析。

中证红利、恒生科技、北证50和创业板目前是指数观察项。如果持有对应基金，请将名称、代码、币种及日线标识一起替换。指数点位不能与基金成本相除；程序会拒绝为指数填写基金成本。指数项可填代表该类敞口的权重，但同一笔持仓不要同时计入指数和对应基金。

恒生科技未填写 `secid` 时，使用腾讯日线接口；其他有 `secid` 的品种使用东方财富日线。港股公开行情可能延迟约15分钟，报告会保留实际报价时间；程序无法将延迟行情变成实时行情。香港/北交所公开接口兼容性不保证；单个品种失败不影响其他品种保存报告。

`premium_alert_pct: 3`（3%）和 `portfolio_growth_alert_weight: 0.30`（30%）是可修改的示例检查线，**没有根据你的个人风险承受能力校准**。它们不是推荐配置，也不触发自动买卖。权重合计不得超过100%；缺失权重不等于零持仓。

## 折溢价输入

默认不根据旧净值推算实时溢价。可从可靠来源取得参考价值，复制并填充 `input_templates/references.csv`：

```powershell
python daily_analysis.py --references input_templates/references.csv
```

|列|要求|
|---|---|
|`asset_id`|与配置中的id相同，例如 `nasdaq_tech`|
|`reference_value`|每份的同期参考价值，正数|
|`asof`|参考价值的实际估值时间，带时区的ISO时间|
|`underlying_asof`|底层定价信息的实际时间，不能填写网页抓取时间来冒充|
|`currency`|必须与交易价格一致|
|`kind`|仅接受 `iopv` 或 `fair_value`|
|`source_url`|必须填写可核实来源|

价格与参考价值、参考价值与底层定价时间，默认各自最多相差15分钟；报价默认最多延迟30分钟。旧的美股收盘净值、没有更新底层价格的跨境IOPV，通常无法通过检查。此时显示“未核实”，不会把数据不足变成高溢价或低溢价结论。你提供的公允价值方法仍需自行核实，时间检查不能证明估值模型正确。

## 网络失败时使用自己的数据

公开采集使用腾讯行情和东方财富日线的**非正式接口**，没有稳定性承诺，字段、代码映射或访问限制可能变化。本工具有基础字段和返回代码校验，但不是交易所授权的实时行情终端。接口无法访问或返回异常时会记录错误并保留报告。

可从券商或其他可靠来源导出数据，填写模板后运行：

```powershell
python daily_analysis.py --input-dir input_templates --references input_templates/references.csv
```

这个模式完全不联网。模板只有表头，未填数据时会生成“缺失”报告。

- `quotes.csv`：`asset_id,price,previous_close,asof,currency,status,source_url`。`status` 为 `ok` 或 `suspended`；时间如 `2026-10-13T09:50:00+08:00`，这只是格式示例。
- `history.csv`：`asset_id,date,close,adjustment,source_url`。每个资产每个日期一行；日期格式 `YYYY-MM-DD`；`adjustment` 为 `qfq`、`price` 或 `total_return`，同一资产不得混用口径。60交易日涨跌至少需要61条收盘价。
- CSV保存为UTF-8；不要放入账户密码或证券账户信息。

## 09:50使用方式

在09:50手动运行即可。`preferred_run_time` 是说明字段，**不会让脚本常驻、延迟执行或自动调度**。需要定时运行时，你可自行在Windows任务计划程序设置工作日09:50执行Python，参数指向本脚本，并设置脚本文件夹为起始位置；电脑需开机。简单工作日计划不识别中国/香港节假日，运行后仍需看报价日期。

“当日有效”只表示报价通过币种和时效校验，**不代表独立确认正在交易或已经复牌**。尤其09:50的跨境ETF应查看停复牌公告。海外现货市场此时可能没有开市；不能把内地ETF盘中涨跌写成美股当天涨跌。

退出码：`0` = 所有配置品种的当日报价通过检查；`2` = 报告已保存，但部分报价缺失/过期/异常；`1` = 配置或输入错误。退出码0不保证全部日线、溢价或交易状态都已核实，请读报告中的各项质量信息。

## 本版的分析边界

这是一套可复核的数据和规则工具。趋势提示支持“观察、保留合理底仓、暂缓集中补仓、复核溢价、评估再平衡”，不预测必涨必跌，也不根据均线单独给个人买卖数量。

全市场热门板块、新闻政策、财报与估值、10/30年国债收益率变化、真实黄金/原油价格和停复牌公告，仍需另接可靠数据或人工核实。本版的强弱排名仅比较关注资产，不能当作全市场热点榜。没有真实完整仓位、成本、投资期限，也不能给出完整账户的压力测试或个性化交易指令。

脚本不需要OpenAI服务。以后可以把生成的Markdown交给AI，结合注明来源和时间的新闻进一步解读。
